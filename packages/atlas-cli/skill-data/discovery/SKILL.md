# atlas

This file is a discovery stub, not the usage guide. Before running any Atlas
command or MCP tool, load the guide the installed CLI serves:

```bash
atlas skills get core      # start here: workflow, tool map, escalation, trust checks
atlas skills list          # every guide this Atlas version serves
```

The CLI serves guide content embedded in the installed version, so this stub
never needs to change between releases.
