# rmcp 3.11 upgrade + MCP transport fixes

## Upgrade
- `packages/atlas-mcp/Cargo.toml`: `rmcp 3.1.0` -> `3.11.0` (lock resolves `rmcp`/`rmcp-macros` 3.11.0).
- Updated `url` 2.5.8 -> 2.5.9 (RUSTSEC-2026-0592), `form_urlencoded` 1.2.3, lockfile transitive refresh.
- `deny.toml`: removed obsolete rmcp advisory ignores (`RUSTSEC-2026-0457`, `-0461`, `-0462`); `cargo deny check` green.

## Latest MCP lifecycle behavior
- rmcp 3.11 treats EOF before `initialize` as `ServerInitializeError::ConnectionClosed`, including after a valid `server/discover` bootstrap. Added `is_clean_preinit_transport_close` in `transport/helpers.rs` and mapped it to `Ok(())` in stdio, stdio test harness, and Unix socket transports.
- Production stdio server now uses `rmcp::transport::stdio_pipes()` (non-blocking Linux pipe transport with fallback).
