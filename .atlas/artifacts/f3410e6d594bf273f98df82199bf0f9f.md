# Decision: Atlas state tracking moves to `.atlas/.gitignore`; artifacts committed

Two policy changes shipped in one session:

1. `.atlas/artifacts/**` is now a committed durable family alongside memories,
   decisions, feedback, memoir, and overview. Skill guides, tests, README,
   SHIPPED, ISSUES, and docs all state the new committed/local split:
   committed = memories, decisions, feedback, memoir, overview, artifacts;
   local-only = sessions, tasks, experience.
2. Atlas no longer relies on root `.gitignore` entries. The tracking policy
   ships inside the state directory as `.atlas/.gitignore` (anchored `/*`
   ignore plus durable-directory re-includes, self-tracking via `!/.gitignore`).
   Root `.gitignore` keeps only the repo-wide `*.md` whitelist; the old
   `.atlas/*` block was replaced with a pointer comment.

## Implementation

- New module `[REDACTED].rs`:
  `ATLAS_GITIGNORE_REL`, `ATLAS_GITIGNORE_MARKER`,
  `ATLAS_GITIGNORE_CONTENT`, and `ensure_atlas_gitignore(repo_root, dry_run,
  force)`. Idempotent: matching file → no write; user-edited file preserved
  unless `--force`; dry-run reports without writing; creates the `.atlas`
  parent dir.
- `apply_init_mode`/`plan_init_mode` (`install/init_modes.rs`) gained a
  mode-independent `gitignore` asset family, so `atlas init` (every mode)
  plans and applies it with the same create/unchanged/refresh/skipped actions
  as the mcp asset.
- `run_install` (`install/mod.rs`) writes it on `atlas install` and reports
  `gitignore_files` in CLI output and the install JSON payload.
- `atlas install --validate-only` gains an `atlas_gitignore` check
  (`install/validation.rs`) that reports a missing or unmanaged file by marker.
- Working tree already has the managed `.atlas/.gitignore` (byte-identical to
  the const so init reports unchanged).

## Verification

- `git check-ignore -v`: memories/artifacts `.md` re-included via
  `.atlas/.gitignore` negations (deeper file overrides root `*.md`);
  `config.toml`, `sessions/**`, `worldtree.db` ignored via `/*`;
  `.atlas/.gitignore` itself tracked via `!/.gitignore`.
- `cargo test -p atlas-cli` (filters gitignore/mode/init_*): 22 unit + 9 CLI
  quality-gate tests pass, including new gitignore lifecycle unit tests and
  updated init plan/dry-run assertions.
- `cargo clippy -p atlas-cli --all-targets -- -D warnings` clean after
  restructuring one collapsible nested `if let` in `run_install`.
- `cargo fmt --all` applied; graph refreshed via `update_graph` (17 files,
  healthy).

## Caveat

Committed artifacts make saved plan/review/handoff bodies permanent repo
history: keep secrets and oversized payloads out of artifacts. Age-based
`purge_saved_context` (30-day default) deletes committed files, which shows
as git deletions.
