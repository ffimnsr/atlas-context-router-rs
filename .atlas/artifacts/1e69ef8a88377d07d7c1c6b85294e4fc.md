## Sections

1. `## Debug a failure` — reproduce first; locate via query_graph /
   resolve_symbol, symbol_neighbors test adjacency, get_context; check wake_up
   recent_runtime_failures, memory_recall + search_decisions for prior
   incidents; fix root cause; regression test; record tool-failure event +
   error_resolved artifact; repo-wide lesson to memory_store.
2. `## Test alongside a change` — find existing tests (symbol_neighbors,
   `tests for <symbol>`, get_context tests:true); regression test with the
   fix; escalation narrow filter -> package -> workspace; flakes are bugs,
   never retry loops.
3. `## Perform an upgrade or dependency bump` — recon dependents
   (symbol_neighbors / get_impact_radius); bump + lockfile; project dependency
   audit when present; breaking-change sweep (explain_change); gates;
   traceability pair with upgrade tag.
4. `## Prepare a release` — gates green; confirm traceability records exist
   (memory_recall by tags); one decision artifact (release scope, verified
   gates, notable changes) + memory row. Explicit line: repo changelog and
   agent-instruction file updates are repo policy, not Atlas workflow.
5. `## Scaffold a new component` — place first (analyze_architecture /
   infer_modules for layer; find_duplicates / find_similar_functions to avoid
   re-implementation); new file or module, minimal public surface, tests
   alongside; update_graph by files; optional overview_export packet;
   traceability pair.
6. `## Coordinate parallel agents` — delegate only disjoint write scopes with
   self-contained context; sub-agents run their own wake_up..stop loop and own
   agent_id partitions; parent synthesizes, saves combined handoff artifact +
   memory pointer; merge_agent_partitions only at deliberate merge points.
7. `## Run periodic hygiene` — event-tied not wall-clock: overview_refresh_plan
   after landings; get_context_stats -> compact_session / purge_saved_context
   on storage pressure; doctor / db_check on suspected corruption; memory
   health on drift; history prune on snapshot growth; feedback search before
   repeating verdicts.

## Core bullets (SKILL.md, `### Failure triage and lifecycle`)

- **Debug a failure.** — reproduce, locate, root cause, regression test,
  error_resolved artifact.
- **Test alongside a change.** — existing tests first, regression with fix,
  narrow-to-wide escalation.
- **Upgrade a dependency.** — recon dependents, audit, sweep, gates,
  traceability pair.
- **Prepare a release.** — gates, records confirm, one decision artifact;
  repo changelog/agent files are repo policy.
- **Scaffold a new component.** — place by layer, avoid duplicates, minimal
  surface, tests, update_graph.
- **Delegate to parallel agents.** — disjoint scopes, self-contained context,
  partitions, combined handoff.
- **Run periodic hygiene.** — event-tied compaction, purge, doctor, memory
  health, history prune.
