macOS CI fingerprint tests failed because the rmcp ToolFixture passed a raw tempdir path while build_graph keys fingerprints by the git-canonical root (/var vs /private/var). Fixed by canonicalizing the fixture root. refactor_parse_validation fuzz target assumed every SupportedPathKind is in the default parser registry; after grammar offload Cpp/Java/C#/PHP/Scala/Ruby/Bash are registry-external, so expectations now come from ParserRegistry::with_defaults().supports(path).
