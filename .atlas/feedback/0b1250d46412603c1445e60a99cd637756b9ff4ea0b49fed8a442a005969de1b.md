## Predicted

Doc parity contract: CLI `data` object should match MCP `structuredContent` for field names and counts across Tools 34-39.

## Actual

CLI `insights duplicates|infer-modules|label-components --json` omit MCP-only fields: duplicates lacks group_count (MCP 5), infer-modules lacks module_count (MCP 29), label-components lacks assignment_count (MCP 5/50); large-functions CLI emits no `candidates` array while MCP does. Conversely CLI duplicates/infer-modules payloads are 415 KB / 1.21 MB at defaults while MCP caps with limit + byte budget.

## Correction

Count/summary fields are added in the MCP dispatch wrapper (structuredContent mirroring) instead of the shared report structs, so `data` and `structuredContent` are not identical. Fix: emit group_count/module_count/assignment_count/candidates from the shared report builders used by both surfaces (packages/atlas-cli/src/commands/insights*.rs vs packages/atlas-mcp/src/tools/analysis.rs), and apply the same default limit/byte budget on the CLI path.
