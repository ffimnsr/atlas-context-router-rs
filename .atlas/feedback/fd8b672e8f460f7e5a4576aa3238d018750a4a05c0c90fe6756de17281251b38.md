## Correction

total_strength is computed by summing or negating an empty/unmatched float set, yielding IEEE-754 -0.0 which serializes as `-0.0`. Normalize to +0.0 before emitting (e.g. `if total == 0.0 { 0.0 } else { total }` or use f64::abs on zero paths).
