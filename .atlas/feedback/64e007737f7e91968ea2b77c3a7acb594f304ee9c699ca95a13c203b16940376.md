## Predicted

Test 7.4 expects list_symbols kind=package to return synthetic Cargo package owners with qualified_name format `package::cargo:...` (e.g. atlas-core, atlas-mcp, atlas-cli).

## Actual

list_symbols returned total=6 package nodes only: 8 language-level parser nodes (go/java/scala fixtures) plus 0 Cargo owners. DB actually contains 25 synthetic `package::cargo:...` nodes under `.atlas/synthetic/owners/package/cargo/*.atlas` (plus 3 atlas registry nodes), so they exist but are filtered out.

## Correction

Synthetic-path exclusion is deliberate: atlas_store_sqlite::store::graph SymbolFilter include_synthetic defaults to false and adds `.atlas/synthetic%` to exclude_prefixes (packages/atlas-store-sqlite/src/store/graph.rs:316-320). list_graph_stats applies the same exclusion (store/lifecycle.rs:512,636). The store supports include_synthetic but the MCP list_symbols schema and the CLI `atlas symbols` never expose it, so Cargo package owners are unreachable through either surface. Fix: add `include_synthetic` to list_symbols input schema + registry descriptor (packages/atlas-mcp/src/tools/registry/) and plumb to SymbolFilter, add `--include-synthetic` to packages/atlas-cli/src/commands/, or amend Test 7.4 to use a surface that exposes synthetic owners.
